# Xcount Fitness 評価システム

パーソナルトレーニングジム「Xcount Fitness」向けの、お客様の変化・現状を評価するための
Webアプリケーションです。以下の項目をお客様ごとに記録し、時系列グラフで確認できます。

- 体重・BMI
- 各部位の皮下脂肪厚(キャリパー法)・体脂肪率(7部位すべて入力時は自動推定)
- 各部位の周囲サイズ(頸部・胸囲・腹囲・臀囲・上腕・前腕・大腿・下腿など)
- 関節可動域(ROM)評価(肩・股・膝・足関節・体幹)
- 筋力評価(握力・背筋力・スクワット/ベンチプレス1RM・プランク保持時間など)
- 姿勢評価(頭部前方位・円背・骨盤傾斜・左右差・O脚/X脚・扁平足などのチェック)

## セットアップ

```bash
cd xcount-fitness
python3 -m venv .venv          # 任意(推奨)
source .venv/bin/activate
pip install -r requirements.txt
```

## 起動方法

```bash
python3 app.py
```

初回起動時にSQLiteデータベース(`data/xcount_fitness.sqlite3`)が自動作成されます。
ブラウザで http://localhost:5000 を開いてください。

## デモデータの投入(任意)

動作確認用にサンプルのお客様・測定履歴を投入できます。

```bash
python3 seed.py
```

## 使い方

1. トップページの「新規お客様登録」からお客様(お名前・性別・生年月日・身長)を登録します。
2. お客様一覧または詳細ページの「測定を記録」から、体重・皮下脂肪厚・周囲サイズ・ROM・
   筋力・姿勢の各評価項目を入力して記録します(項目はすべて任意入力、未入力の項目は
   グラフ・履歴上で `-` 表示になります)。
3. お客様詳細ページで、体重・体脂肪率の推移、周囲サイズの推移、ROMの最新値、筋力評価の
   推移、姿勢評価の推移などをグラフで確認できます。
4. 測定履歴の各行から編集・削除ができます。

## 体脂肪率の自動推定について

7部位(胸部・腹部・大腿部・上腕三頭筋部・肩甲骨下部・腸骨上部・腋窩中央部)の皮下脂肪厚を
すべて入力すると、Jackson & Pollock の7部位法とSiriの式により体脂肪率を自動推定します
(お客様の性別・生年月日が登録されている必要があります)。体脂肪率を手入力した場合は
その値が優先されます。

## 技術構成

- Python 3 / Flask(サーバーサイドレンダリング, Jinja2)
- SQLite(標準ライブラリ `sqlite3`。追加のDBサーバー不要)
- Chart.js(CDN経由、グラフ描画)

ビルドツールや外部フレームワークは使用していないため、`pip install` 後すぐに起動できます。
